基线选择

公开版选择历史提交 05df483 中 2026-05-19 的用户返修 v4，而不是最早自动初稿。提交说明明确结果章节经本人仔细审定；后续另有一个写作风格转换节点，可帮助界定这一版本所处的阶段。公开仓库没有导入原项目提交历史。

原稿的功能总量和组分系数混用已校订；变量筛选按实际的相关性与生态优先序命名；矩阵相关不把所有样点对当作独立重复。修改日志记录段落编号与哈希，不附被移除的样点信息。

保留与脱敏

保留真实性状编码、分类阶元、文献来源、审阅与冲突，以及研究的聚合统计。导师提供的群落输入、由其派生的有无矩阵、标准化副本、原始坐标、样本级环境记录、距离矩阵、点图、PDF 原稿、旧压缩包和旧 Git 对象均未进入发布目录。合成数据使用独立随机数从零生成，不按真实分布拟合。

仅给样本改名或只删除当前文件，无法清除原值及 Git 历史。因此本仓库是经白名单导出的全新仓库，提交日期采用本次发布日期；旧提交编号仅用于说明历史来源，不伪装成新仓库的历史。

真实性状矩阵包含 37 个属级单元、37 个编码列，有效值 971／1369，缺失 398。5 月 15 日单轮新增 47 个有效单元格，6 个冲突未合入。源文献全文和整库未打包；来源链接及归属保留。

早期来源选择曾排除 SG（同属其他种），后期定向检索批次又接受了部分明确标记 SG 的候选。公开版保留这一版本演变和审阅说明，不能宣称所有值都是精确属级证据，也不能把减少零距离本身视为生物学真实性证明。review_decisions.csv 可查看后期例外，conflicts.csv 可查看未合入的单元格。
